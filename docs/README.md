# Documentación histórica

Esta carpeta conserva documentación del sistema WinForms y de su análisis de
migración. No describe la operación vigente ni debe ser la fuente primaria para
nuevos desarrollos.

- `refactor/`: inventarios, análisis y planes históricos de WinForms.
- `deployment/`: guías históricas de empaquetado e instalación de escritorio.
- `legal/`: material legal asociado al sistema anterior.
- `legado/`: documentos que antes estaban en la raíz del repositorio.

La documentación vigente del producto está en
[`web/docs/`](../web/docs/README.md). La arquitectura aprobada para cualquier
cambio nuevo es [`web/docs/ARQUITECTURA.md`](../web/docs/ARQUITECTURA.md).
